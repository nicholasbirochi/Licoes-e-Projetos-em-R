# Lições e projetos em R

Anotações, exemplos e exercícios de estudo da linguagem R. As pastas seguem a sequência das aulas, dos primeiros cálculos até estruturas de dados, funções e um projeto interativo de cadastro de notas.

## Por onde começar

- `1 - Básico`: primeiros comandos e uma calculadora.
- `2 - Vetores` e `3 - Sequência`: acesso, operações e criação de sequências.
- `4 - Matrizes`, `5 - Arrays` e `6 - Fatores`: organização e transformação dos dados.
- `7 - Listas` e `8 - Data Frames`: estruturas compostas e operações em tabelas.
- `9 - Funções`: comparações, condições, repetição e funções próprias.
- `Projeto/ProjetoFinal.R`: cadastro de alunos, três notas e cálculo da média.

## Como usar

Abra os arquivos `.R` no RStudio e execute os trechos enquanto acompanha os resultados. Os exercícios e materiais de apoio ficam junto dos assuntos correspondentes.

Para iniciar o projeto final, execute no console do RStudio, a partir da raiz deste repositório:

```r
source("Projeto/ProjetoFinal.R")
```

O programa pede os dados no console e usa `View()` para mostrar a tabela ao final. É um exercício de estudo, sem armazenamento permanente dos cadastros.
